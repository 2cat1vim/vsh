# vsh | portable shell w built-in binaries.

**vsh** is a shell written entirely in C. It ships as its own standalone binary and follows its own way of working — it is not a clone or wrapper of bash, zsh or any other existing shell.

vsh is free, open source, and **written by humans only**.

---

## Features

- Pure C, no external runtime
- Its own binary: `vsh`
- Its own design and behavior, built from scratch
- Open source, free to use, study, modify and share

## Binaries
- print > .bin/print
```
$ print aaaaa\naaaa
aaaaa
aaaa
```
- see > .bin/see
```
$ see test0.c test1.c
test0.c:
......
test1.c:
......
```
- list > .bin/list
```
$ list {args or not}
file0 mode... byte... uid... gid... date  00:00
file1 mode... byte... uid... gid... date 11:00
n 02
```
## Building

```sh
git clone <repo-url>
cd vsh
./setup.sh
```

## Running

```sh
./vsh
```
